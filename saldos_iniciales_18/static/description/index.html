Importacion de Saldos Iniciales y Facturas AFIP

Migra tus saldos pendientes y facturas historicas de forma masiva y profesional.

Modulo Gratuito

Licencia Publica LGPL-3

Este modulo esta disenado especificamente para la localizacion argentina (l10n_ar). Permite importar comprobantes de ventas y compras directamente desde los archivos CSV exportados por AFIP (Mis Comprobantes), automatizando la carga de saldos y la creacion de contactos.

Caracteristicas Principales

Dos Modos de Importacion

  • Saldos Iniciales: Importa el saldo total (sin IVA desglosado), ideal para arranques de sistema.
  • Nuevos Documentos: Importa facturas completas con desglose de IVA (21%, 10.5%, etc.), percepciones y tasas.

Automatizacion Total

  • Creacion de Partners: Crea automaticamente clientes y proveedores por CUIT si no existen.
  • Multimoneda: Conversion inteligente de "DOL" a USD y "PES" a ARS.
  • Tipos de Cambio: Actualiza automaticamente la tasa de cambio en Odoo segun el archivo.

Como funciona?

1. Subir

Sube el CSV de AFIP (Compras o Ventas).

2. Analizar

El sistema valida CUITs, duplicados e inconsistencias.

3. Revisar

Obten un reporte detallado con estadisticas de importacion.

4. Procesar

Genera las facturas y contactos con un solo clic.

Seguridad y Control

El modulo cuenta con un sistema de Verificacion de Duplicados para el importador de "Nuevos Documentos", evitando que se cargue la misma factura dos veces buscando por socio de negocio, tipo de documento y numero.

Ademas, si algo no sale como esperabas, puedes utilizar la funcion de Rollback (mientras las facturas esten en borrador) para limpiar la importacion y volver a empezar.
