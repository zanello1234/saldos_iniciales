Initial Balances Import

Import receivable and payable balances from AFIP CSV files

Reference module for importing initial balances and new invoices from AFIP CSV files in Odoo. It allows you to quickly migrate historical data or import periodic batch invoices.

Features

  • Import initial balances (total amount)
  • Import new invoices with VAT details
  • Duplicate verification
  • Multi-currency support (USD/ARS)
  • Automatic exchange rate updates
  • Automatic partner creation

How it works

1. Upload your AFIP CSV file (Purchases or Sales).
2. Click on "Analyze File" to verify the data and detect potential issues.
3. Review the analysis report.
4. Click on "Process File" to create the invoices and partners.
